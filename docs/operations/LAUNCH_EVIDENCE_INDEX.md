# Launch Evidence Index

The release owner must attach one immutable evidence bundle containing:

- approved commit SHA and production image digests;
- Quality CI release-evidence artifact;
- migration and database smoke output;
- manual staging report from `MANUAL_LAUNCH_TEST_PLAN.md`;
- accessibility and mobile-browser results;
- security review and abuse-test results;
- backup restore and application rollback drill evidence;
- SMTP sender approval and sign-in test evidence;
- JazzCash sandbox scenario and reconciliation evidence;
- provider/model/task AI evaluation and human approvals;
- named production administrators and access-review record;
- open-defect list with severity and accepted owner;
- go-live decision, approvers, timestamp and rollback owner.

Do not place credentials, payment payloads, learner identifiers, authentication codes or raw model prompts in the evidence bundle.
