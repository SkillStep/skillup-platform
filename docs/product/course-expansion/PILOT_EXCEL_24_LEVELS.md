# Wave 1 pilot blueprint — Excel & Google Sheets for Work (24 planned levels)

**Status:** Draft outline for SME review; zero levels authorized for automatic publication.
**Course slug:** `excel-google-sheets-work`
**Audience:** First-time spreadsheet users, students and small-business staff.
**Prerequisite:** Ability to use a browser and enter sample data into a table.
**Outcome:** Clean a small dataset, calculate useful totals and create an understandable business tracker.
**Capstone:** Reusable sample sales/expense workbook and a brief insights summary, with a self-check rubric; do not promise automatic grading of uploaded work.
**Session design:** Approximately 5–10 minutes of active practice per level, excluding time spent working in a separate spreadsheet tool.

## Module 1 — Clean and Structure Data

| Level | Draft title | Assessable learner objective |
| --- | --- | --- |
| 1 | Identify Spreadsheet Rows and Columns | Distinguish headers, records, cells and data types in a real order sheet |
| 2 | Set Up a Clean Data Table | Choose useful column names and one-record-per-row structure |
| 3 | Keep Dates, Money and Numbers Consistent | Spot data type problems that distort a summary |
| 4 | Find Missing and Duplicate Records | Identify blanks, duplicates and legitimate repeated orders |
| 5 | Sort, Filter and Inspect Data | Use filtering to answer a specific business question without deleting data |
| 6 | Checkpoint: Clean Sample Orders | Correct a 25-row synthetic order dataset using a documented checklist |

## Per-level challenge specification

Each level needs at least three **different** reviewed interaction prompts, mixing subject-specific multiple choice, data interpretation, ordering/matching, error diagnosis and short responses when appropriate. Challenge style must test the chosen spreadsheet outcome, not reuse a generic “confirm the requirement, check the evidence, then act” answer.

Example drafts, not approved answers:

- **Level 4:** Given six synthetic order rows, identify whether two nearly identical rows are duplicates or separate transactions, and explain which field would resolve ambiguity.
- **Level 10:** Given five synthetic line items and a category field, choose a SUMIF criterion/range combination and predict the correct subtotal.
- **Level 17:** Compare two chart images built from the same approved synthetic data; identify why a truncated vertical axis changes the reader's impression.
- **Level 22:** Given a sample sheet containing internal customer contact information, choose the least-privilege sharing option. All test data must be fictional.

## Assessments and artifacts

- **Baseline:** Six original questions sampling concepts in each module, before instruction. Store results against reviewed content version.
- **Module checkpoint:** One meaningful task every six levels, with targeted remediation for a missed skill.
- **End assessment:** Six new questions with matched outcome/difficulty, not repeats of the baseline keys.
- **Capstone asset:** Fictional CSV dataset, annotated sample workbook (where asset export is implemented), instructions and a self-check rubric. Never require personal business data.
- **Success rubric:** Correct data types; reliable formulas; transparent chart; coherent written explanation; safe sharing. Require all critical correctness/privacy items to pass and allow retry with remediation.

## Editorial review gate

An Excel/Sheets-fluent subject reviewer checks formula examples in **both supported spreadsheet products** (or explicitly labels product-specific features); independent editor checks difficulty, mobile alternative and readability. Record actual review timestamp and source/tool versions. Do not use the historical generic seed review timestamp for these new lessons.

The course cannot be tagged published or Premium-available until all 24 levels and three challenges per level pass schema checks, expected keys, accessibility, frontend player QA and staging certification. The user-facing card must show actual available levels, not the 24-level planning target.
