# Reviewed Seed Content

This directory will contain versioned, reviewable seed content and non-secret source metadata for local development and approved launch paths.

- copyrighted source material without permission;
- private learner responses or production exports;
- raw model transcripts containing personal data;
- unreviewed generated pages intended for publication;
- credentials or paid-provider datasets.
