# Content Schema Package

Versioned schemas for skills, learning paths, modules, lessons, levels, challenges, explanations, objectives, translations, source references, review decisions and publications.

Rules:

- all public learning content is versioned;
- learner attempts reference the exact content version presented;
- AI output must validate before entering review;
- draft, rejected and low-quality content cannot become public by default;
- source, reviewer, freshness, locale and discoverability fields are first-class data.
