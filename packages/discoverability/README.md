# Discoverability Package

Shared utilities and policies for SEO, AEO, GEO and bilingual public content.

Responsibilities:

- canonical and locale URL construction;
- metadata and social cards;
- robots and sitemap eligibility;
- breadcrumbs and internal-link validation;
- visible-content-matched JSON-LD;
- hreflang and translation relationships;
- thin-content, accidental-noindex/index and orphan-page checks.

This package cannot publish content or expose private learner routes. See `docs/discoverability/SEO_AEO_GEO_STANDARD.md`.
