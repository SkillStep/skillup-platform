# Analytics Package

Versioned privacy-safe event names, payload schemas and consent rules.

The package covers:

- discovery and acquisition;
- registration and onboarding;
- learning attempts, completion and mastery;
- retention and streaks;
- premium funnel, payment and entitlement quality;
- AI usage, cost and content quality;
- public-page discoverability and Core Web Vitals.

Events use stable identifiers and bounded enumerations. They do not contain passwords, tokens, payment secrets, raw private learner text or unnecessary personal data.
