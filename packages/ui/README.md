# UI Package

Shared accessible design tokens and components for public discovery, learner gameplay, checkout and administration.

Rules:

- no application routing, database or payment logic;
- keyboard, focus, contrast, touch and reduced-motion behavior are part of component acceptance;
- public components remain server-rendering compatible where possible;
- Urdu/RTL layout support is designed into tokens and primitives;
- game components provide non-drag and non-color alternatives.

See `docs/brand/BRAND_SYSTEM_V1.md` and `docs/design/DESIGN_ACCESSIBILITY_PERFORMANCE_STANDARD.md`.
