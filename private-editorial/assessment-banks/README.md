# Private assessment banks (not for public GitHub)

Place independently rewritten practice and assessment evaluator banks here for local/staging import only.

- Expected files: `<course-slug>.practice.json`, `<course-slug>.assessments.json`
- Do **not** commit JSON banks to the public SkillUp repository.
- See `docs/product/course-expansion/PRIVATE_ASSESSMENT_BANK_OPERATIONS.md` and issue #281.
- Synthetic examples for automated tests belong under `tools/` or package test fixtures, never here as “final” keys.
